== Purpose

This repository contains sanctioned individuals, entities, and vessels from the
United States Office of Foreign Assets Control (OFAC) sanctions lists.

== Source

* **Authority**: United States Department of the Treasury, OFAC
* **URL**: https://ofac.treasury.gov/sanctions-lists
* **SDN List**: https://sanctionslistservice.ofac.treas.gov/api/PublicationPreview/exports/SDN_ADVANCED.ZIP
* **Consolidated (Non-SDN)**: https://sanctionslistservice.ofac.treas.gov/api/PublicationPreview/exports/CONS_ADVANCED.ZIP
* **Format**: XML (in ZIP archives)
* **Update Frequency**: As updated by OFAC
* **Country Code**: US

== Legal Basis

OFAC administers sanctions under multiple legal authorities:

* *International Emergency Economic Powers Act (IEEPA)*
* *Trading with the Enemy Act (TWEA)*
* *Foreign Assistance Act*
* Various Executive Orders
* Specific legislation (e.g., CAATSA)

== Lists Included

* **SDN (Specially Designated Nationals)**: Entities whose assets are blocked
* **Consolidated Sanctions List**: Non-SDN lists including:
  * FSE (Foreign Sanctions Evaders)
  * NS-PLC (Non-SDN Palestinian Legislative Council)
  * SSI (Sectoral Sanctions Identifications)
  * etc.

=== Schema Types

Each YAML file follows one of the schema types:

. **Announcement Schema** - Standard sanction announcements with `sanction_details`
. **Legal Instrument Schema** - Executive orders, statutes, regulations

Schema files are located in `schemas/`:

* `schemas/us-announcement.yml` - For sanction list announcements
* `schemas/us-legal-instrument.yml` - For legal instruments
* `schemas/document-types.yml` - Supporting schema for document types
* `schemas/organizations.yml` - Supporting schema for organizations

== Source Data Format

=== Sanction Announcement Schema

[source,yaml]
----
# yaml-language-server: $schema=../../schemas/us-announcement.yml
---
id: us/sdn-2024-001
announcement:
  title: "Treasury Sanctions Russian Entities"
  url: "https://home.treasury.gov/news/press-releases/..."
  publish_date: "2024-01-15"
  document_id: "FR Doc. 2024-12345"
  document_type: us/designation
  authority: us/ofac
  publisher: us/treasury
  lang: en
  content: |
    The Department of the Treasury's Office of Foreign Assets Control...

sanction_details:
  - entity:
      type: organization
      uid: "12345"
      name:
        full_name: "EXAMPLE CORPORATION LTD"
        script: Latn
      aliases:
        - name: "Example Corp"
          type: aka
          category: strong
      identifiers:
        - type: Registration Number
          number: "12345678"
          issuing_country: RU
      addresses:
        - street: "123 Main Street"
          city: "Moscow"
          country: "Russia"
          country_code: RU
      remarks: "For additional information on..."

    measures:
      - type: asset_freeze
        description:
          en: "All property and interests in property are blocked"
      - type: trade_restriction
        description:
          en: "Trade restrictions apply"

    programs:
      - UKRAINE
      - RUS

    reasons:
      - category: "national_security"
        description:
          en: "Operating in the defense sector of the Russian Federation economy"

    period:
      effective_date: "2024-01-15"
      is_indefinite: true

legal_citations:
  - legal_instrument_id: us/eo-14024
    citation_type: legal_basis

group_id: us/russia-sanctions-2024-01
----

=== Entity Types

The US sanctions list contains the following entity types:

Person:: Individual persons subject to sanctions
Organization:: Legal entities, companies, and organizations
Vessel:: Ships and maritime vessels
Aircraft:: Aircraft subject to sanctions

== Knowledge Graph Integration

This repository's source YAML data feeds into the Ammitto knowledge graph
using a normalized structure.

=== Data Flow Architecture

The harmonization process transforms source YAML data into JSON-LD knowledge graph nodes:

....
┌─────────────────────┐     ┌─────────────────────┐     ┌─────────────────────┐
│   Source YAML       │     │   Ammitto Gem       │     │   JSON-LD Output    │
│   (sources/)        │────▶│   Transformer       │────▶│   (api/)            │
│                     │     │                     │     │                     │
│ • Announcement      │     │ • UsAnnouncement    │     │ • Entity nodes      │
│ • Sanction details  │     │ • UsEntity          │     │ • Entry nodes       │
│ • Legal instruments │     │ • UsMeasure         │     │ • Regime nodes      │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
....

== Updating Data

Data is automatically updated via GitHub Actions when OFAC publishes new data.

To manually update:

[source,shell]
----
# From the ammitto gem directory
bundle exec ruby exe/ammitto fetch us --format yaml --output-dir ./sources/sanction-lists/sdn-list
----
